# Splat Studio

A self-contained, offline WebGL2 visualization combining Gaussian-splat rendering with an interactive PCA-inspired geometry rescue switch. Drag to orbit, zoom with wheel or pinch, and switch REGULARIZE on to see procedural splats become surface-shaped.

The scene is generated procedurally in the browser. Its local shape alignment is an illustration inspired by PCAsplat; it does not train a model, compute paper losses, or reproduce the authors' training pipeline. No third-party code or assets are used.

Research credit: Vitor Matias, Filipe Nascimento, Kiyohiro Nakayama, João Paulo Lima, Márcus Lobo, Gordon Wetzstein, Leonidas Guibas, and Tiago Novello, [PCAsplat: Gaussian Splatting with Local PCA Regularization](https://arxiv.org/abs/2610.11011), arXiv:2610.11011.
